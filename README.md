# Java Terminal Battleship

![Java](https://img.shields.io/badge/Java-17-orange)

A simple console-based implementation of the classic Battleship game, developed in Java. This project was created to practice object-oriented programming concepts, arrays, and logic flow.

## Features

- Random ship placement.
- Interactive user input via terminal.
- Status tracking (Hit, Miss, Kill).
- Input validation (non-numeric and out-of-range inputs handled).

## How to Run

1. Ensure you have Java installed.
2. Compile the files: `javac Main.java Ship.java`
3. Run the game: `java Main`

## Concepts Applied

- Object-Oriented Programming (Classes & Objects)
- Array manipulation
- Control flow (Loops & Conditionals)
- Exception handling (try-catch)

## What I Learned

- How to apply OOP principles separating responsibilities between classes
- Exception handling with try-catch for robust user input
- Array manipulation and state tracking to prevent duplicate hits
